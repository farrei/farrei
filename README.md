## Projeto em destaque: [PrintFix](https://github.com/farrei/printfix)

Quem trabalha com suporte conhece o chamado "deu erro aqui" acompanhado de um print. O PrintFix lê esse print com um modelo de IA com visão, identifica o erro e a causa provável e devolve um chamado pronto: título, categoria, prioridade, diagnóstico, passo a passo e quando escalar.

<p align="center"><img src="https://raw.githubusercontent.com/farrei/printfix/main/docs/demo.png" alt="PrintFix gerando um chamado" width="720"></p>

Python, Streamlit e Pydantic, com 12 testes automatizados e CI no GitHub Actions. Roda em modo demo, sem chave de API:

```bash
git clone https://github.com/farrei/printfix.git && cd printfix
pip install -r requirements.txt
streamlit run app.py
```
